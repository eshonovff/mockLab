## 1. {{brand}} деген эмне

{{brand}} — иштеп чыгуу, сыноо жана прототиптөө үчүн жасалма REST API түзүүчү булуттук кызмат.
Сиз ресурстун схемасын аныктайсыз, ал эми {{brand}} суроо боюнча ишенимдүү жасалма дайындарды
түзөт — кызмат сиздин атыңыздан чыныгы production дайындарын сактабайт жана башкарбайт.

## 2. Бул демо кызмат

{{brand}} иштеп чыгуу жана сыноо максаттары үчүн берилет. Аны чыныгы, купуя же жеке дайындарды —
өзүңүздүкүн да, башкалардыкын да — сактоо үчүн колдонбоңуз. Түзүлгөн дайындар табияты боюнча
жасалма; өзүңүз киргизген нерселер (долбоордун аттары, ресурстардын схемалары жана mock API
аркылуу түзгөн же өзгөрткөн ар кандай жазуулар) бир жолку, production эмес мазмун катары
каралышы керек.

Биз сактаган ар кандай дайыныңыздын узак сакталышына кепилдик бербейбиз. Долбоорлор, ресурстар
жана сиз түзгөн ар кандай өзгөртүүлөр — техникалык тейлөө, кыянаттык колдонуунун алдын алуу же
кызматтын өзгөрүүлөрүнүн натыйжасында да — эскертүүсүз өзгөртүлүшү, кайра орнотулушу же
өчүрүлүшү мүмкүн.

## 3. Аккаунттар

Долбоор түзүү үчүн аккаунт керек. Сиз аккаунтуңуздагы аракеттер жана сырсөзүңүздүн купуялыгы
үчүн жооптуусуз. Сиз чыныгы электрондук почта дарегин көрсөтүшүңүз керек жана башка адамдын же
уюмдун атынан иш алып бара албайсыз.

## 4. Уруксат берилген колдонуу

{{brand}} кызматын төмөнкүлөр үчүн колдонбоңуз: мыйзамды бузуу; чыныгы жеке, каржылык,
медициналык же башка купуя дайындарды сактоо же өткөрүү; документтештирилген суроо чектеринен
ашкан трафик жиберүү сыяктуу кызматты бузууга аракет кылуу; мыйзамсыз же зыяндуу бир нерсени
түзүү же таратуу.

## 5. Сиздин мазмунуңуз

Сиз түзгөн схемаларга, долбоордун аттарына жана ар кандай ыңгайлаштырылган жазууларга карата
сизде болгон укуктар сизде калат. Сиз бизге бул мазмунду сактоого жана аны кайра берүүгө —
анын ичинде долбооруңуздун ачык mock API endpointi аркылуу коомчулукка ачык түрдө — уруксат
бересиз. Түзүлгөн жасалма дайындар эч кимге таандык эмес: алар алгоритмдик түрдө түзүлөт жана
чыныгы дайындардан алынган эмес.

## 6. Аккаунтту өчүрүү

Аккаунтуңузду каалаган убакта башкаруу панелиндеги жөндөөлөрдөн өчүрө аласыз. Аккаунтту өчүрүү
долбоорлоруңузду, ресурстарыңызды жана сактаган бардык дайыныңызды калыбына келтирүү мөөнөтүсүз
биротоло өчүрөт.

## 7. Кепилдиксиз

{{brand}} "болгон бойдон" берилет, эч кандай кепилдиксиз. Биз иштөө убактысын, дайындардын
сакталышын же кандайдыр бир максатка ылайыктуулугун кепилдебейбиз.

## 8. Өзгөртүүлөр

Кызмат өнүккөн сайын бул шарттарды жаңырта алабыз. Өзгөртүүдөн кийин колдонууну улантуу
жаңыртылган шарттарды кабыл алганыңызды билдирет.
