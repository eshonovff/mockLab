Ресурстың схемасы — өрістердің реттелген тізімі. Әр өрістің `name`, `type` мәні бар, ал түріне
байланысты кішкене `options` жиынтығы болуы мүмкін. Өрістердің реті бір нақты себеп үшін маңызды:
`template` өрісі тек сол тізімде өзінен бұрын тұрған өрісті сілтей алады — төмендегі `template`
жолын қараңыз.

Өріс атаулары кіші әріптен басталуы керек және тек әріптерден, сандардан және астыңғы сызықтан
тұруы керек. Ресурста ең көбі 30 өріс болуы мүмкін. Әр генерацияланған жазба автоматты түрде `id`
мәнін де алып жүреді — сіз оны өзіңіз ешқашан анықтамайсыз, ал `id` деп атаған өрісіңіз нағыз
`id`-дың пайдасына үнсіз еленбей қалады.

## Анықтамалық кесте

| Түрі        | Баптаулары                                       | Мысал шығысы                                        |
| ----------- | ------------------------------------------------ | --------------------------------------------------- |
| `index`     | —                                                | `0`, `1`, `2`, … (жазбаның реттік орны)             |
| `uuid`      | —                                                | `"a1b2c3d4-5e6f-7890-abcd-ef1234567890"`            |
| `firstName` | —                                                | `"Amelia"`                                          |
| `lastName`  | —                                                | `"Nguyen"`                                          |
| `fullName`  | —                                                | `"Amelia Nguyen"`                                   |
| `email`     | —                                                | `"amelia.nguyen42@example.com"`                     |
| `phone`     | —                                                | `"+1 555 019 2231"`                                 |
| `avatar`    | —                                                | аватар суретінің URL мекенжайы                      |
| `image`     | `width`, `height` (екеуі де міндетті емес)       | берілген өлшемдегі сурет URL мекенжайы              |
| `city`      | —                                                | `"Tashkent"`                                        |
| `country`   | —                                                | `"Uzbekistan"`                                      |
| `street`    | —                                                | `"482 Birchwood Ave"`                               |
| `word`      | —                                                | `"vivid"`                                           |
| `sentence`  | `min`, `max` сөз саны (міндетті емес)            | `"The quiet fox waited by the door."`               |
| `paragraph` | `min`, `max` сөйлем саны (міндетті емес)         | қысқа lorem-стиліндегі абзац                        |
| `number`    | `min`, `max` (әдепкі `0`–`1000`)                 | `742`                                               |
| `price`     | `min`, `max`, `symbol` (әдепкі белгісіз)         | `"48.19"`, немесе `symbol: "$"` болғанда `"$48.19"` |
| `boolean`   | `true` болу ықтималдығы — `probability`, `0`–`1` | `true`                                              |
| `date`      | `from`, `to` ISO жолдары (әдепкі 2015–2025)      | `"2021-06-14T09:32:00.000Z"`                        |
| `enum`      | `values` — бос емес жол массиві                  | `values`-тен таңдалған бір мән                      |
| `static`    | `value` — кез келген тұрақты JSON мәні           | әрдайым дәл `value` өзі                             |
| `template`  | `template` — `{{field}}` толтырғыштары бар жол   | бұрынғы өрістерден құрастырылған жол                |

## `template` түрі

`template` — өз мәнін генерациялаудың орнына басқа өрістерді оқитын жалғыз түр. Оның `template`
баптауы — жай ғана жол; онда `{{fieldName}}` кездескен жерде, ол толтырғыш `fieldName` деп
аталған өрістің осы жазба үшін генерациялаған мәнімен алмастырылады. Бұл тек схемада _бұрынырақ_
анықталған өрістер үшін жұмыс істейді — үлгі әлі жегілмеген өрісті сілтей алмайды. Кең тараған
пайдалану жағдайы: схемада бұрынырақ `firstName` және `lastName` өрісі болса, кейінгі `email`
өрісі байланыссыз мән генерациялаудың орнына `"{{firstName}}.{{lastName}}@example.com"` деген
`template` өрісі болып, есімге сай email қалыптастыра алады.

## Детерминизм, қысқаша

Әр өріс түрі осы жазбадағы басқа әрбір өріспен бірдей seed-делген псевдокездейсоқ тізбектен мән
алады, сондықтан дәл сол схема, seed және жазба индексі әрдайым дәл сол жазбаны — өріс-өрісіне
дейін — қайтарады. Механизмнің толық сипаттамасы
[Генерация қалай жұмыс істейді](/docs/how-generation-works) бетінде берілген; мұнда маңыздысы —
өрістің _баптауларын_ өзгерту тек сол өрістің болашақ шығысын өзгертеді, ал схемадағы өрістерді
қайта реттеу немесе басқа жерге өріс қосу бар жазбаларға берілген id-лерді араластырмайды — id
мәндері схеманың қалған бөлігінен тәуелсіз генерацияланады.

## Ресурс деректерін алу

Осының бәрі деректерді қалай оқитыныңызды өзгертпейді — қандай өрістері болса да, әр ресурс дәл
осылай оқылады:

```js
const response = await fetch("https://{{domain}}/m/demo7k2m9x/products");
const products = await response.json();
```

```jsx
import { useQuery } from "@tanstack/react-query";

function ProductList() {
  const { data: products } = useQuery({
    queryKey: ["products"],
    queryFn: () => fetch("https://{{domain}}/m/demo7k2m9x/products").then((res) => res.json()),
  });

  return <pre>{JSON.stringify(products, null, 2)}</pre>;
}
```
