Мұнда еш нәрседен нағыз шақыруға болатын эндпоинтке дейінгі ең қысқа жол көрсетілген. Бұл шамамен
бес минутты алады.

## 1. Аккаунт жасаңыз

`/register` бетінде email және құпия сөзбен тіркеліңіз. Сіз басқару тақтасына түсесіз — әзірге
жоба жасамағандықтан, ол бос болады.

## 2. Жоба жасаңыз

Жоба — жай ғана атаулар кеңістігі: ол бір немесе бірнеше ресурсты ұстайды және оның әр эндпоинт
URL мекенжайында пайда болатын `key` мәніне иелік етеді. **Жаңа жоба** түймесін басып, оған атау
беріңіз де, {{brand}} сізге кездейсоқ жоба кілтін жасап береді — мысалы, `demo7k2m9x` секілді. Бұл
кілтті сіз өзіңіз ешқашан таңдамайсыз; ол эндпоинт URL мекенжайын жоба атауыңыздан болжап табуға
болмайтындай ету үшін бар.

## 3. Ресурс жасаңыз

Жобаңыздың ішінде ресурс жасап, оған атау беріңіз — мысалы, `products`. Ресурс — бір схема: әрқай-
сысында өз түрі бар өрістер тізімі. Сынап көру үшін үш өріс қосыңыз:

| Өріс атауы | Түрі    | Ескертпе                           |
| ---------- | ------- | ---------------------------------- |
| `title`    | word    | генерацияланған бір сөз            |
| `price`    | price   | `symbol` баптауын `$` етіп қойыңыз |
| `inStock`  | boolean | true/false                         |

Сіз қосқан әр өріс сол экрандағы тірі алдын ала қарау кестесін жаңартады, сондықтан клиенттік
кодтың бір жолын жазбай тұрып-ақ нақты генерацияланған жолдарды көре аласыз. **Жазба саны**
баптауын қажетіңізге қарай орнатыңыз — жылдам сынау үшін 50, "жазба саны шектелмейді" деген
сөздің шынымен де солай екенін көру үшін 100 000. Қандай санды таңдасаңыз да, бір беттің жауап
уақыты іс жүзінде өзгермейді, өйткені {{brand}} бір сұраныс үшін бір беттен артық жазба
генерацияламайды.

## 4. Эндпоинтіңізді шақырыңыз

Ресурсыңыздың эндпоинті оны жасаған сәтте бірден жұмыс істей бастайды — бөлек "жариялау" немесе
"деплой" қадамы жоқ. Толық URL мекенжайы бір үлгіге сай келеді:

```
https://{{domain}}/m/{project-key}/{resource-name}
```

Жоғарыдағы жоба мен ресурс үшін бұл:

```js
const response = await fetch("https://{{domain}}/m/demo7k2m9x/products");
const products = await response.json();
console.log(products[0]);
// { id: "a1b2c3d4-...", title: "vivid", price: "$48.19", inStock: true }
```

React компонентінде TanStack Query арқылы дәл сол шақыру былай көрінеді:

```jsx
import { useQuery } from "@tanstack/react-query";

function ProductList() {
  const {
    data: products,
    isPending,
    isError,
  } = useQuery({
    queryKey: ["products"],
    queryFn: () => fetch("https://{{domain}}/m/demo7k2m9x/products").then((res) => res.json()),
  });

  if (isPending) return <p>Loading…</p>;
  if (isError) return <p>Something went wrong.</p>;

  return (
    <ul>
      {products.map((product) => (
        <li key={product.id}>
          {product.title} — {product.price}
        </li>
      ))}
    </ul>
  );
}
```

Осымен бітті — өз серверіңізсіз-ақ беттеуі, сүзгілеуі, сұрыпталуы және толық CRUD-ы бар нағыз
REST ресурсы дайын. Осы жерден бастап: [Схема және өріс түрлері](/docs/schema-and-field-types)
беті ресурсыңызға қолжетімді барлық өріс түрін қамтиды, ал
[Сұраныс параметрлері](/docs/query-parameters) беті тізім эндпоинтіне URL арқылы жасауға болатын
барлық нәрсені қамтиды.
