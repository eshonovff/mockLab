{{brand}} қатаң қолданатын әрбір шектің қысқаша сипаттамасы, сондықтан ресурстың қалай
әрекет ететіні жоба барысында ешқашан күтпеген жерден шықпайды.

## Сұраныс жиілігінің шегі

Әр жоба өзінің `/m/...` эндпоинттеріне қатысты минутына 60 сұранысқа шектелген, ресурс бойынша
емес, жоба кілті бойынша есептеледі — сондықтан үш ресурсы бар жоба барлығына ортақ бір
60-сұраныстық бюджетті бөліседі. Әрбір жауапта сұраныс сәтті болды ма, болмады ма — ағымдағы
терезеде қанша сұраныс қалғанын көрсететін `X-RateLimit-Remaining` тақырыбы бар, сондықтан
жақсы жазылған клиент бұғатталғанша күтпей, алдын ала баяулай алады.

Шектен асып кетсеңіз, `429 Too Many Requests` жауабын аласыз, ал `Retry-After` тақырыбы терезе
қайта басталғанша неше секунд күту керек екенін айтады.

```js
async function fetchWithBackoff(url) {
  const response = await fetch(url);
  if (response.status === 429) {
    const retryAfterSeconds = Number(response.headers.get("Retry-After"));
    await new Promise((resolve) => setTimeout(resolve, retryAfterSeconds * 1000));
    return fetchWithBackoff(url);
  }
  return response;
}
```

```jsx
import { useQuery } from "@tanstack/react-query";

function useProducts() {
  return useQuery({
    queryKey: ["products"],
    queryFn: () => fetch("https://{{domain}}/m/demo7k2m9x/products").then((res) => res.json()),
    // TanStack Query already retries failed requests with backoff by default —
    // a 429 here is retried automatically without any extra code.
    retry: 3,
  });
}
```

## Бет көлемі

`limit` әдепкі бойынша 10, ал ең көбі 100 — одан көп сұраныс қате бермейді, ол жай ғана 100-ге
дейін үнсіз азаяды. Ресурстың жалпы `count` мәніне ешқандай шек жоқ; шек тек бір бетте қанша
жазба қайтарылатынына қатысты. Беттеу баптауларының толық жиынтығы үшін
[Сұраныс параметрлері](/docs/query-parameters) бетін қараңыз.

## 10 000 жазбалық сұрыптау/сүзгілеу шекарасы

Сұрыптау, сүзгілеу және іздеу тек 10 000 немесе одан аз жазбасы бар ресурстарда қолжетімді.
Одан жоғарыда сұраныс сәтті орындалып, дұрыс беттелгенмен, бұл параметрлер үнсіз еленбейді —
бұл қате емес, өйткені сұраныстың өзі жарамсыз емес, сондықтан `X-MockLab-Notice: sort-filter-
disabled-above-10000` жауап тақырыбымен белгіленеді. Толық түсіндірме
[Генерация қалай жұмыс істейді](/docs/how-generation-works) бетінде.

## CORS

Әрбір `/m/...` жауабында `Access-Control-Allow-Origin: *` және нағыз `OPTIONS` preflight
өңдеушісі бар, сондықтан эндпоинтіңізді кез келген доменнен браузер JavaScript-інен прокси-сіз-
ақ тікелей шақыруға болады. Осы құжаттама бойында сипатталған бірнеше меншікті жауап тақырыбы
(`X-Total-Count`, `X-RateLimit-Remaining` және басқалары) `Access-Control-Expose-Headers`
арқылы нақты ашылған, сондықтан олардың кез келгені үшін `response.headers.get(...)`
браузердегі кодта да, тек серверлік немесе командалық жол клиентінде ғана емес, жұмыс істейді.

## Шынымен шектелмегені

Қатаң шегі жоқ жалғыз нәрсе — `count`, яғни ресурстың жалпы жазба көлемі. Бүкіл мәні де осында:
жазбалар сақталудың орнына сұраныс бойынша генерацияланатындықтан, миллион жазбасы бар ресурс
серверге он жазбасы бар ресурспен бірдей түседі. Жоғарыдағы шектер қызметті ортақ пайдаланатын
әрбір жобаға әділ болу үшін бар, ал жеке ресурс не білдіре алатынын шектеу үшін емес.
