## Эндпоинтимди чакыруу үчүн API ачкычы же аутентификация керекпи?

Жок. Эндпоинт URL'уңуздагы долбоор `key`си (`/m/{project-key}/{resource-name}`) сурамдарды
долбооруңузга алкактайт — жиберилүүчү өзүнчө API ачкыч же auth хедери жок. Бул ресурсту эч
кандай сыр жоготпостон түз браузер JavaScript'инен чакырса болот дегенди билдирет, бул
маанилүү, анткени CORS так браузер коду аны түз чакыра алышы үчүн демейки боюнча иштетилген.

## Эмне үчүн менин `price_gt=50` чыпкам иштебейт?

Төрт гана чыпка суффикси бар: `_gte`, `_lte`, `_ne` жана `_like` — `_gt` же `_lt` (катуу
чоң/кичине, "же барабар" эмес) жок. Бирок `price_gt=50` жараксыз катары четке кагылбайт;
таанылган суффикске дал келбегендиктен, ал так `price_gt` деп аталган талаа боюнча жөнөкөй тең
дал келүү чыпкасы катары каралат, ал схемаңызда болушу мүмкүн эмес дээрлик — ошондуктан
унчукпай эч нерсеге дал келбейт. Бүтүн сандык талаада катуу теңсиздикти билдирүү үчүн
`price_gte=51` (же `_lte=49`) колдонуңуз, же `price` талаасы үчүн "же барабар" чегин кабыл
алыңыз, анткени генерацияланган ондук санда так дал келүү сейрек чынында керек нерсе.

## Ар бир сурамда так ошол эле жазууну ала алам бекен?

Ооба, жана сиз аны мурда эле аласыз — бул [Генерация кантип
иштейт](/docs/how-generation-works) барагындагы детерминизм кепилдиги. Так ошол эле, өзгөрбөгөн
ресурс ар бир сурам үчүн, кайсы клиентте болбосун, мыйзам мойнуна алгыдай, өзгөртпөй же reset
кылмайынча, ар дайым бирдей маалымат кайтарат. Бул белгилүү бир күтүлгөн маанилерге карата
сынактарды же демо скрипттерин жазууну коопсуз кылат.

## Эмне үчүн менин иреттөө/чыпкалоо сурамым токтоп калды?

Ресурсуңуздун жазуу `count`ун текшериңиз. Иреттөө, издөө жана чыпкалоо 10 000 же андан аз
жазууда гана жеткиликтүү; андан жогору болсо, алар ката бербестен унчукпай өчүрүлөт, жана бул
болгондо жооп `X-MockLab-Notice: sort-filter-disabled-above-10000` алып жүрөт. Толук картина
үчүн [Чектөөлөр жана адилеттүү колдонуу](/docs/limits-and-fair-use) барагын караңыз.

## Жазуу өчүрүлгөндө анын `id`си кайра колдонуу үчүн бошоп калабы?

Жок — өчүрүлгөн жазуунун `id`си эч качан кайтпайт. Өчүрүү ошол id жоголгонун белгилеген
оверрайд катары сакталат, генерациянын өзүн жокко чыгаруу катары эмес, ошондуктан ресурс reset
кылынганга чейин ошол id ишенимдүү түрдө "өчүрүлгөн" дегенди билдире берет.

## Ар кандай UI тилдери бир ресурс үчүн ар кандай жасалма маалымат генерациялай алабы?

Ооба, жана булар атайылап көз каранды эмес. Ресурс өзүнүн жасалма маалымат `locale`суна ээ —
`en`, `ru` жана башка — ресурсуңузду конфигурациялаганда бир жолу коюлат, бул кайсы тилде
аттар, шаарлар жана даректер генерацияланарын башкарат. Анын дашбордуңуз кайсы тилде
көрсөтүлгөнүнө эч тиешеси жок; дашбордду бир тилде карап, ресурс башка тилде жасалма маалымат
генерациялашы мүмкүн.

## Бүтүн баракчанын ордуна бир жазууну кантип алам?

Тизме жообунан алдыңыз бар id колдонуп, жалгыз жазуу URL'ун түз эле `GET` кылыңыз,
`/m/{project-key}/{resource-name}/{id}`:

```js
const list = await fetch("https://{{domain}}/m/demo7k2m9x/products").then((res) => res.json());
const first = await fetch(`https://{{domain}}/m/demo7k2m9x/products/${list[0].id}`).then((res) =>
  res.json(),
);
```

```jsx
import { useQuery } from "@tanstack/react-query";

function useProduct(id) {
  return useQuery({
    queryKey: ["products", id],
    queryFn: () =>
      fetch(`https://{{domain}}/m/demo7k2m9x/products/${id}`).then((res) => res.json()),
    enabled: Boolean(id),
  });
}
```

## Бул жерде бир нерсе көрүп жатканыма дал келбейт — эми эмне кылам?

Бул документтер боюнча айтылган ар бир жооп хедери (`X-Total-Count`, `X-RateLimit-Remaining`,
`X-MockLab-Notice`, `Retry-After`) чыныгы, текшерилүүчү сигнал, ички гана жүрүм-турум эмес —
дал келбестик дээрлик ар дайым сурамдын чыныгы хедерлеринен түшүндүрүлөт. Бир нерсе бузулду
деп ойлоордон мурун ошол жерден баштаңыз.
