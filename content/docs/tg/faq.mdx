## Оё барои муроҷиат ба эндпоинти худ ба калиди API ё аутентификатсия ниёз дорам?

Не. `key`-и лоиҳа дар URL-и эндпоинти шумо (`/m/{project-key}/{resource-name}`) он чизест, ки
дархостҳоро ба лоиҳаи шумо доира мекунад — ҳедери алоҳидаи калиди API ё аутентификатсия лозим
нест. Ин имкон медиҳад, ки захира мустақиман аз JavaScript-и браузер бидуни ягон сирри
дарздиҳанда даъват шавад, ки муҳим аст, зеро CORS ба таври пешфарз маҳз барои он фаъол аст, ки
коди браузер бевосита даъват карда тавонад.

## Чаро филтри `price_gt=50`-и ман кор намекунад?

Танҳо чор суффикси филтр вуҷуд дорад: `_gte`, `_lte`, `_ne` ва `_like` — `_gt` ё `_lt` (комилан
бузургтар/хурдтар, бидуни "ё баробар") вуҷуд надорад. `price_gt=50` ҳамчун нодуруст рад
намешавад; азбаски он ба ҳеҷ суффикси эътирофшуда мувофиқат намекунад, он ҳамчун филтри
мувофиқати дақиқ дар майдоне бо номи айнан `price_gt` баррасӣ мешавад, ки қариб яқин дар схемаи
шумо вуҷуд надорад — пас хомӯшона ба ҳеҷ чиз мувофиқат намекунад. Барои ифодаи нобаробарии
комил дар майдони бутун `price_gte=51` (ё `_lte=49`)-ро истифода баред, ё марзи "ё баробар"-ро
барои майдони `price` қабул кунед, зеро мувофиқати дақиқ дар рақами даҳдаҳии сохташуда кам вақт
он чизест, ки воқеан мехоҳед.

## Оё метавонам ҳамон сабтро дар ҳар дархост бигирам?

Бале, ва шумо аллакай мегиред — ин кафолати детерминизм аз
[Тарзи кори сохтан](/docs/how-generation-works) аст. Ҳамон захира, тағйирнаёфта, барои ҳамон
дархост дар ҳар муроҷиат, аз ҳар клиент, то абад ҳамон додаҳоро бармегардонад, магар он ки шумо
ба он бинависед ё онро аз нав танзим кунед. Маҳз ин аст, ки навиштани санҷишҳо ё скрипти
намоиширо бар зидди арзишҳои интизории мушаххас бехатар месозад.

## Чаро дархости тартиб/филтри ман якбора кор кардан бас кард?

`count`-и сабтҳои захираи худро санҷед. Тартибдиҳӣ, ҷустуҷӯ ва филтр танҳо дар 10,000 сабт ё
камтар дастрасанд; аз он боло онҳо хомӯшона ғайрифаъол мешаванд, на хато медиҳанд, ва ҷавоб
ҳедери `X-MockLab-Notice: sort-filter-disabled-above-10000`-ро дорад, вақте ки ин рӯй медиҳад.
Барои тасвири пурра ба [Маҳдудиятҳо ва истифодаи одилона](/docs/limits-and-fair-use) нигаред.

## Оё нест кардани сабт `id`-и онро барои истифодаи дубора озод мекунад?

Не — `id`-и сабти нестшуда ҳеҷ гоҳ бармегардад. Нест кардан ҳамчун тағйироте нигоҳ дошта
мешавад, ки он id-ро нест мениҳад, на ҳамчун бекор кардани худи сохтан, пас ҳамон id боэътимод
то аз нав танзим шудани захира маънои "нестшуда"-ро дорад.

## Оё ду забони гуногуни UI барои ҳамон захира додаҳои сохтаи гуногун месозанд?

Бале, ва инҳо қасдан мустақиланд. Захира `locale`-и додаҳои сохтаи худро дорад — `en`, `ru` ва
ғайра — ки як бор ҳангоми танзими захира таъин мешавад ва идора мекунад, ки номҳо, шаҳрҳо ва
суроғаҳо дар кадом забон сохта мешаванд. Ин ҳеҷ алоқае бо он надорад, ки дашборди шумо дар кадом
забон намоиш дода мешавад; шумо метавонед дашбордро дар як забон тамошо кунед, дар ҳоле ки
захира додаҳои сохтаро дар забони дигар месозад.

## Чӣ гуна ба ҷои тамоми саҳифа як сабт бигирам?

Ба URL-и як сабт мустақиман `GET` фиристед, `/m/{project-key}/{resource-name}/{id}`, бо
истифодаи id-е, ки аллакай аз ҷавоби рӯйхат доред:

```js
const list = await fetch("https://{{domain}}/m/demo7k2m9x/products").then((res) => res.json());
const first = await fetch(`https://{{domain}}/m/demo7k2m9x/products/${list[0].id}`).then((res) =>
  res.json(),
);
```

```jsx
import { useQuery } from "@tanstack/react-query";

function useProduct(id) {
  return useQuery({
    queryKey: ["products", id],
    queryFn: () =>
      fetch(`https://{{domain}}/m/demo7k2m9x/products/${id}`).then((res) => res.json()),
    enabled: Boolean(id),
  });
}
```

## Чизе дар ин ҷо бо он чизе, ки мебинам, мувофиқат намекунад — акнун чӣ?

Ҳар ҳедери ҷавобе, ки дар тамоми ин ҳуҷҷатҳо зикр шудааст (`X-Total-Count`,
`X-RateLimit-Remaining`, `X-MockLab-Notice`, `Retry-After`) сигнали воқеан санҷидашаванда аст, на
рафтори танҳо дохилӣ — номувофиқат қариб ҳамеша аз он чизе, ки ҳедерҳои воқеии дархост мегӯянд,
шарҳдиҳанда аст. Пеш аз тахмин задани он, ки чизе вайрон аст, аз он ҷо оғоз кунед.
